# OMRANCO BURGER

موقع عمرانكو برجر — المنصورة.

## Development

تحتاج Node.js و npm:

```sh
git clone https://github.com/elrefaeey/omran.git
cd omran
npm i
npm run dev
```

افتح `http://localhost:8080`.

## Scripts

- `npm run dev` — سيرفر التطوير
- `npm run build` — بناء للإنتاج
- `npm run preview` — معاينة البناء
